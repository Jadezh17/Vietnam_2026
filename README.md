# Vietnam Trip Planner · 12–21 Dec 2026

A single-page planner for 9 nights in Vietnam: Ho Chi Minh City → Hoi An → Hanoi → Ha Long Bay cruise → Hanoi, then on to Seoul. It has a day-by-day itinerary, a map, things to do, restaurant and hotel shortlists, and a to-do list to tick off.

The first time you open the site on a device it asks for the trip code (or you can open the trip link). Enter it once and every change — ticks, restaurants, itinerary adds, photos — saves to a shared Supabase database, so everyone on the trip sees the same plan. Choose "Just look around" to browse a copy whose changes stay in your own browser.

Photos marked "Wikimedia Commons" are used under their listed licences; see each place's photo credit. Other photos come from the hotels' websites, saved Instagram reels and a post shared by a friend, and are for personal use only.
